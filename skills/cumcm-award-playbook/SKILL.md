## 二、获奖点（10 条，摘要为最高杠杆）

一等奖共性，按杠杆从高到低：

1. **摘要 5 段式**（占 ~30% 总分，最高杠杆）：背景→任务拆解→各问方法+定量结果→灵敏度→创新推广；**≥3 个定量结果**，600–900 字。
2. **正文章节结构**：问题重述→问题分析→假设→符号→模型建立与求解（主体 60–70%）→灵敏度→评价与推广→参考文献（≥10 条 GB/T 7714）。
3. **图表密度**：每子问 ≥1 流程图 + ≥1 结果图；全文 18–25 个图；matplotlib/seaborn，字号 ≥9pt，不套 Excel 默认配色。
4. **模型命名变体**：不用 textbook 名，起「改进/限定词 + 核心模型 + 复合方法」名（如"动态权重 AHP-熵权组合评价模型"），≥2 修饰词。
5. **子问题复用链**：Q3 显式调用 Q1 结果（"将问题一得到的 X 作为本节输入…"）。
6. **假设支撑度**：每条假设带依据（文献/数据观察/物理意义），3–7 条。
7. **灵敏度深度**：一等奖做**多变量联合扰动**（≥3 参数，LHS/Sobol），给出定量稳健区间；仅 OAT 是二等奖水平。
8. **真自我批判**：缺点 ≥3 条，每条 = 命名方法 + 估算改进空间 + 说明代价，不写套话。
9. **摘要亮点信号词**：创新表述 + 定量结果 + 稳健性 + 推广，每段一个。
10. **附录代码**：首行标注对应论文哪一节，中文注释完整，50–300 行，无调试残留。

**实测硬指标**（91 篇一等奖，median）：摘要 992 字、图 8 张、表 6 张、公式 24 个、引用 28 条、全文约 2.3 万字。完整分位见 empirical.json。

## 三、横向对比——把论文「做深」的核心手段

省一和国奖的差距，一半靠「横向对比」补齐。**定义**：在论文中主动构造对照系，让模型的优劣、稳健性、创新性变得可量化、可验证。

六个维度（详见 `references/horizontal_comparison.md`）：

1. **基线对比**（baseline）：每子问 ≥1 个基线（经典方法/简单启发式/附件历史数据），报告"较基线提升 X%"。
2. **多候选模型对比**：选型阶段 ≥3 个**结构性不同**候选模型，用对比表 PK「精度/时间/可解释性/数据需求」再选优。
3. **官方答案/现实对标**：关键小问结果与官方参考或现实数据对标——这是省一推国掉档的头号原因。
4. **多参数/多场景横向对比**：热力图、三维曲面图展示多维参数对比，一目了然。
5. **融合 vs 单一方法对比**：如熵权+AHP 组合赋权，用优化反解权重系数 α，对比单一赋权。
6. **灵敏度横向对比**：多参数联合扰动 + 稳健区间对比表。

**铁律**：每张对比表都要落到一个结论——"X 比 Y 好在哪、好多少、为什么"。

## 四、省一 → 国奖：差距在哪

**一句话**：省一 = 模型正确有效，停在「能用」；国奖 = 模型优雅有深度 + 系统反思 + 学术呈现 + 摘要杀伤力 + 关键小问答案准。

四大跃迁点（详见 `references/provincial_to_national.md`）：

1. **模型的优雅性与深度**：国奖模型更简洁但抓住本质矛盾，或建立多层模型体系；省一往往"正确但平庸"。
2. **分析的系统性与反思性**：多维系统分析 + 坦诚讨论局限性/假设合理性/改进方向。
3. **表达的学术性与专业性**：图表精美、引用规范前沿、行文精准学术化。
4. **摘要的杀伤力**：千锤百炼，让评委一眼看到亮点。

**省一没进国奖的头号硬门槛**：**关键小问的答案精度**。
- 2024 B 省一推国落选：第二问结果与官方答案不符。
- 2021 C 国二（错失国一）：第四问误差偏大。
- 结论：答案不准，优雅/深度/呈现都白搭；答案对了才有资格比「软实力」。

**省一常见短板**（对应 anti_patterns 编号）：摘要无定量结果(A1)、不与基线对比(E4)、仅 OAT 灵敏度(F2)、模型无改进(C1)、套话式自我批判(H1)、子问题各做各(G1)、图表 Excel 配色(E3)。

## 五、官方评阅标准与格式红线（讲评会口径）

官方「优秀论文评析/赛题讲评」的结论（详见 `references/official_review_criteria.md`）：

- **两级评阅，初评单篇只读 5–10 分钟**——摘要 + 图表 + 结果决定生死。
- **摘要一页四要素**：解决什么问题 / 用什么方法 / 得到什么数值结果 / 结果说明什么。
- **2025 官方数据**：本科国一 0.48%（294 队）、国二 1.96%（1204 队）；68311 队参赛。
- **格式红线（触线即出局）**：第 1 页承诺书 + 第 2 页编号页 + 第 3 页摘要页；正文尽量 20 页内（老模板"22–25 页"已过时）；附录源码必须完整可运行（缺或跑不通 = 取消资格）；全文匿名；PDF≤20MB；**2025 新规 AI 工具使用报告**。
- **评阅核心 6 条**：问题导向非算法炫技 / 假设合理性（高频失分）/ 结果检验 / EDA 显性化 / 模型对比选型理由充分 / 轻算法重思想。

## 六、使用协议

**场景 A：备赛**（赛前）——读真题库 + 获奖点，用往年题做全真模拟，重点练摘要 5 段式 + 基线对比。

**场景 B：复盘**（赛后，尤其"省一想冲国奖"）——对照 `provincial_to_national.md` 逐条自评：关键小问答案准不准？有没有横向对比？灵敏度是 OAT 还是联合扰动？

**场景 C：论文深度提升**（写作中）——把 `horizontal_comparison.md` 的六个维度逐项过一遍，每张对比表落到一个结论。

**与 Top-math-group 的衔接**：本技能是「知识/经验层」，Top-math-group 是「过程层」。在 Top-math-group 的 stage 3（模型选型）加载「多候选模型对比」，stage 5（子问题求解）加载「基线对比」，stage 7/8（评价/写作）加载「灵敏度横向对比 + 官方对标」，stage 9（终审）加载「省一短板清单」逐条对照。

**与底层数据的关系**：获奖点/反模式/实测分位已存在于 `mathmodel-skill/competitions/cumcm/`，本技能不复制，按需引用。若需把阈值改实测，直接读 empirical.json。
