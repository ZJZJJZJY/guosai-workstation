# 近五年国赛真题库（2021–2025）

> 题号规律：本科组选 A/B/C，专科组选 D/E。近年 F 题并入 B。来源：全国大学生数学建模竞赛官网（mcm.edu.cn）历年赛题 + 数模知识库。

**获奖点提示**：A 题重"机理准确 + 数值结果对标"；C 题重"约束完整 + 结果可解释"。

## 五年命题趋势总结（横向看五年）

1. **A 题五年全考「物理/工程机理 + 优化」**：准备 A 题 = 微分方程/几何建模 + 数值求解 + 参数灵敏度。
2. **C 题五年全考「数据驱动 + 优化/分类」**：准备 C 题 = EDA + 预测/分类 + 决策闭环。
3. **B 题在漂移**：从"评价/几何"（2021/2022）→"几何+优化"（2023）→"决策优化"（2024）→"机理+数据"（2025）。
4. **官方导向（讲评会）**：问题导向 > 算法炫技；轻算法重思想；假设合理性是高频失分项；模型对比选型理由必须充分；2024 起 EDA 显性化。

## 选题建议（横向对比五年竞争格局）

- **A 题**：物理/工程背景，选的人相对少（涉及物理），适合"机理建模 + 数值求解"强队；答案对参数敏感，关键小问对标要准。
- **C 题**：数据题，选的人最多、竞争最卷（神仙打架），适合"数据 + 编程"强队；必须 EDA 显性化 + 基线对比。
- **B 题**：近年"决策优化"属性强，适合"优化建模"强队；官方参考答案对标是掉档关键。
