## 1. 反模式速查（按类别，每条 = 问题 → 避免动作）
**摘要（A1-A5）**
- 无定量结果 → 全文 ≥3 个定量数值。
- 不分段长段堆砌 → 5 段式（背景→任务→各问方法+结果→灵敏度→创新推广）。
- 摘要与正文数值不符 → 正文定稿后最后写摘要。
- 关键词空泛 → 4-6 个，含 ≥2 个方法词。
- 字数过短/过长 → 目标 748-1146 字（实测中位 992）。

**建模（B/C/F/G/H）**
- 假设无支撑 → 每条假设标注依据（文献/数据观察/物理意义）。
- 假设 >10 条 → 收敛到 3-7 条。
- 假设 <3 条 → 补充维度（合理性/简化/适用条件）。
- 符号复用/无单位/先用后定义 → 符号表：符号+单位+首次定义页。
- 抄教科书模型名 → 复合命名（≥2 修饰词）。
- 模型与题型不匹配 → 按题型-模型映射表选型。
- 候选模型同族 → ≥3 个结构性不同族的候选。
- 选型理由弱 → 四维说明：拟合度+规模+时间+文献支撑。
- 模型不验证 → 写 50 行 toy demo 先验证逻辑。
- 不做灵敏度 → 必做；仅 OAT → ≥3 参数联合（LHS/Sobol）。
- 扰动幅度不实 → ±5%/±10%/±20% 三档。
- 不报稳健区间 → 给临界边界/相变点。
- 子问题各做各 → 符号统一 + 后问显式引用前问结果。
- 模型族冲突 → 显式说明切换条件，统一推导。
- 套话式自我批判 → 每条=(a) 命名方法+(b) 改进空间估算+(c) 代价。
- 优点夸大 → 用数据/对照支撑。
- 推广空泛 → ≥2 个具体应用场景。

**求解（D/E）**
- 代码无注释 → 中文注释 + 标注对应论文小节。
- 无 sanity check → 边界/退化用例先验。
- 量级离谱 → 量纲检查。
- 随机种子缺失 → 统一 seed，可复现。
- 运行 >1h → 时间预算+规模降维。
- 只报数值 → 补"数值含义"。
- 无基线 → ≥1 个基线，报"较基线提升 X%"。

**写作（I/J）**
- 公式不编号 → 章节级统一编号。
- 引用不规范 → GB/T 7714，≥10 条。
- 中英无空格 → "用 Python 实现"式规范。
- 三人全栈（无分工） → 建模/编程/写作角色主责明确。
- 选题摇摆 → 24h 内定题不再改。
- 写作拖到最后 → day2 下午起并行写作。

**图表（E/I2/格式蒸馏）**
- 不做可视化 → 每子问 ≥1 流程图 + ≥1 结果图。
- Excel 默认配色 → matplotlib/seaborn，字号 ≥9pt。
- 图题空泛 → "动作+对象+条件"式。
- 表题空泛 → "内容+对比维度"式。
- 滥用加粗 → 仅创新点/关键数值/模型名。

**附录（§10+D1）**
- 开头无说明 → 首行注释对应论文章节。
- 调试残留 → 删除 print/临时文件/ipynb 调试笔记。
- 注释不全 → 中文注释完整。
- 篇幅失衡 → 与论文匹配（50-300 行/段）。

## 2. 未获奖真实案例
1. **2024 B 福建推国一 → 终评国二**（多源高置信：BoNing-Gu 公开代码+作者自述+本地蒸馏）：
   - 方法链路完整（序贯抽样+期望成本闭式+0-1 整数规划+仿真+Q4 三次回归矫正），作者自述"看上去没啥问题"。
   - 潜在掉档点：①为防死循环把"是否拆解"与检测**强制同步**，偏离原题的"可选决策"语义（官方高频失分项：假设合理性）；②未与官方答案对标（关键小问数值硬门槛）；③Q4 用纯拟合驱动而非机理校正（违反"轻算法重思想"）；④仓库含调试笔记本（若进支撑材料即触附录红线）。
   - 教训：**做对了流程 ≠ 得高分**；假设立场、答案对标、机理显著性、支撑纯洁度都是隐性红线。
2. **2024 B 省一推国落选**（本地高置信）：第二问结果与官方参考答案不符 → 教训：**关键小问数值是硬门槛**，答案不对则优雅/深度/呈现都归零；每问解完立即对标。
3. **2021 C 国二（错失国一）**（本地高置信）：第四问误差偏大 → 推测约束没考虑全 → 教训：多目标题务必枚举约束并验证边界。

## 3. 官方评审规则红线（触线即出局）
- 两级评阅（赛区→全国），报送保底省一；初评每篇 **5-10 分钟**——摘要+图表+结果决定生死。
- 第 1 页承诺书、第 2 页编号页、第 3 页摘要页（≤1 页），正文第 4 页起；**不要目录**。
- 正文尽量 **≤20 页**（2025 修订口径，"22-25 页"已过时）。
- 全文**匿名**（不得出现学校/姓名/队号）。
- **附录必须含全部完整可运行源码：缺失或不可运行 = 取消评奖资格**。
- PDF ≤20MB、支撑材料 ZIP ≤20MB。
- **2025 新规：AI 工具使用报告**——如实申报、独立完成、不得与队外讨论、不得进讨论平台。

## 4. 头号硬门槛：关键小问答案精度
- 优先级：**答案准确 > 模型优雅 > 深度反思 > 呈现**。答案不准，后面全部白搭。
- 每问解完立即与官方答案/现实对标；多目标题枚举约束验证边界；标定类问题用机理校正而非纯拟合。
