# model_notes — 模型速查补充（跨竞赛通用）

完整目录：`<mm>/references/model_catalog.md`（60+ 模型）；算法原理：`<mmd>/assets/01..07`。此处只列"国一高频组合"：

| 组合模式 | 适用 | 国一常见用法 |
|---|---|---|
| 机理建模 + 数据校正 | 物理/工程题（2023A/2024A/2025B） | 先建机理方程（几何/热/流），再用数据拟合/校正参数，替代纯黑箱 |
| 多模型加权融合 | 预测/评价题（2024C/2025E） | AHP+熵权组合赋权（用优化反解权重 α），对比单一赋权 |
| 自适应/动态参数 | 时序/决策题（2023C/2024B） | 滑动窗口重估参数、贝叶斯更新、滚动优化 |
| 离散化 + 精确/启发式混合 | 优化题（2021RGV/2023A/2024B） | 连续问题离散化后用 DP/整数规划，大规模再用启发式（GA/TS/PSO） |
| 多目标分解（加权/字典序） | 多目标题（2023C/2024C） | 权重法+ε-约束+Pareto 前沿，给定量权衡区间 |
| 反问题/逆优化 | 机理题（2025B 碳化硅） | 由观测反推参数（正则化+非线性最小二乘） |
