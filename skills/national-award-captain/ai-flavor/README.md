# ai-flavor — 去AI味模块

## 轻度（终稿必做，stage 8.5）
运行 `<adw>`（anti-defensive-writing）：
1. 列防御式写作实例：disclaimers、反复"本文不主张"、过度 hedge（"可能""或许","在一定程度上"）、段落以 limitations 开头、负向框架、"not X but Y"、"It is worth noting that"、"to be clear"。
2. 区分「必要限制」（影响结论效度/方法学透明）与「多余防御」（纯怕被误解）。
3. 改写：claim 前置、正向 scope、用证据而非道歉；必要限制集中到方法/讨论/limitations 一节，不散落摘要/引言/结论。

## 深度（可选）
再用 `anti-slop` 全文扫套路化表达：模板化开场（"随着...的发展"）、空洞过渡（"综上所述"滥用）、AI 高频句式、万能总结段；逐条改写为具体、有信息量的表达。

## 例子
- 前：`我们的结果可能表明该方法在某些条件下具有一定优势。`
- 后：`在 20 组基准测试中，本方法平均误差降低 12.3%（较基线），对噪声不敏感（σ∈[0,0.2]）。`
