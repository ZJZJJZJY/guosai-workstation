# 队友接入指南（转发给队友）

> 你收到的是小队共用的"国奖冲刺工作站"（私有仓库）。按下面 6 步，10 分钟上手。

## 0. 先决条件
- **Windows** + **VS Code**
- **Python 3.11+**
- VS Code 装这三个 AI 插件：**DeepSeek Harness**、**Claude Code**、**OpenAI Codex**（各自账号登录；多AI 评审走本地 CLI，**不需要 API key**）
- （可选）**Git**（clone 用）；**LaTeX**（TeX Live / MiKTeX，出论文用）

## 1. 拿到仓库（私有）
队长先加你为协作者：仓库 **Settings → Collaborators → Add people** → 你接受邀请。
```powershell
git clone https://github.com/ZJZJJZJY/guosai-workstation
cd guosai-workstation
```

## 2. 一键安装
```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```
自动：把 22 个技能落到 `~\.agents\skills\` 和 `~\.claude\skills\`（软链优先，失败自动复制）→ 装 Python 依赖 → 生成 `multi_ai/config.json`。

## 3. 开工
**新开一个对话**（DeepSeek Harness 或 Claude Code），说：
```
冲刺国奖 / 开始建模
```
即启用整套总指挥（10 阶段编排 + 近三年国一知识模块 + 多AI 评审）。

## 4. 想先看懂再做？（建议）
让 Codex 读仓库：
> "读一下这个仓库的 `README.md` 和 `docs/安装与下载指南.md`，然后跑 `setup.ps1`。"

- `docs/安装与下载指南.md`：每个技能**从哪来、放哪、必须命令、获奖论文去哪找**。
- `docs/协作方案与DeepSeek任务清单.md` / `docs/国赛工作站交接手册-ClaudeCode.md`：三方分工与接力协议。

## 5. 三人分工
| 角色 | 谁 | 干什么 |
|---|---|---|
| 编排+写作 | **Claude Code** | 流程编排、论文/摘要/排版、维护 `state/decision_log.json` |
| 数据+计算 | **DeepSeek（DSH）** | 清洗/EDA/求解/优化/灵敏度/复算；交付"可复现代码+结果表+指标" |
| 评审 | **GPT（Codex）** | 模型路线/摘要/图表/严谨复核（官方答案对标等） |

## 6. FAQ
- 三个 AI 插件**没登录** → 多AI 评审自动降级（不阻塞），分别登录即可。
- **`pymoo` 装不上** → 用 `deap`（已含）手写 NSGA-II。
- **中文路径报错** → 项目目录用英文/不带空格路径。
- **LaTeX 缺宏包** → `tlmgr install <包>`（TeX Live）或 MiKTeX 自动装。
