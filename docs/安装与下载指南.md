## 0. 最省事路径（推荐）
仓库已自带全部必要的 22 个技能 + 知识模块，所以**你不必从网上一个个下**。只需：
```powershell
git clone <你的仓库URL> 国赛工作站
cd 国赛工作站
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```
`setup.ps1` 会自动：把 `skills/` 里的技能落到 `~\.agents\skills\` 和 `~\.claude\skills\`（软链优先）→ 装 Python 依赖 → 生成 `multi_ai/config.json`。完成后**新开会话说“冲刺国奖/开始建模”**即用。

**三个可信来源**（按优先级）：

   - `git clone https://github.com/zhanwen/MathModel` → 找 `国赛论文/2023年优秀论文/` 等
3. **CSDN/知乎/B 站汇总帖**（质量参差，防真假）
   - 例：`https://blog.csdn.net/2401_86936045/article/details/141719882`（历年汇总，国一学长整理）

**下载后放哪**（供 `math-modeling` 优秀论文库使用）：

## 7. 常见问题 FAQ
- **Junction/软链失败**（`setup.ps1` 会自动复制）：已做降级；若你要软链，用 `New-Item -ItemType Junction`，Windows 需同一分区或管理员。
- **pymoo 装不上**（个别环境轮子解包被拦）：改用 `deap`（已在 requirements）手写 NSGA-II，或用 `scipy.optimize`。
- **中文乱码/路径**：项目目录避免中文路径；文件名用 ASCII。
- **LaTeX 缺宏包**：TeX Live 用 `tlmgr install <包>`；MiKTeX 自动装。
- **三端 CLI 没登录**：`multi_ai` 会自动降级（单模型评审），不影响主流程；分别登录 DSH/Claude/Codex 即可恢复多AI。
